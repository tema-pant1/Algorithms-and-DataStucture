# Реализованные возможности проекта

Проект на C++ содержит собственные реализации динамического массива, двусвязного списка и стека, алгоритм сортировки Timsort, а также модуль вычисления арифметических выражений в обратной польской записи.

## Возможности

### 1. Динамический массив — `DynamicArray<T>`

Реализован шаблонный контейнер на основе динамически выделяемого массива.

- Хранение элементов и отслеживание текущего размера и ёмкости.
- Автоматическое увеличение ёмкости в два раза при заполнении.
- Добавление элемента в конец (`push_back`).
- Вставка элемента по индексу (`insert`).
- Удаление элемента по индексу (`remove`).
- Доступ к элементам через `operator[]` с проверкой индекса.
- Обмен элементов местами (`swap`).
- Разворот всего массива или заданного диапазона (`reverse`).
- Копирование элементов и вывод массива в консоль.
- Вывод текущего размера и ёмкости (`status`).

### 2. Двусвязный список — `DLList<T>`

Реализован шаблонный список из узлов, содержащих данные и ссылки на следующий и предыдущий узлы.

- Добавление элемента в конец (`push_back`).
- Вставка элемента по индексу (`insert`).
- Удаление элемента по индексу (`earase` — имя метода в исходном коде).
- Поиск узла по индексу (`find`).
- Получение указателей на голову и хвост списка.
- Вывод содержимого и состояния списка.

### 3. Стек — `stack<T>`

Реализован шаблонный стек на основе узлов двусвязного списка.

- Добавление элемента на вершину (`push`).
- Удаление верхнего элемента (`pop`).
- Получение верхнего элемента (`top`).
- Проверка на пустоту (`is_empty`).
- Получение размера (`GetSize`).
- Доступ к элементам по индексу через `operator[]`.
- Удаление элемента по индексу (`remove`).
- Вывод содержимого и состояния стека.

### 4. Сортировка Timsort

Реализован алгоритм сортировки целочисленного `DynamicArray<int>`.

- Поиск естественных монотонных серий (*runs*) во входном массиве.
- Разворот серий, обнаруженных в порядке убывания.
- Вычисление минимальной длины серии (`GetMinrun`).
- Увеличение коротких серий сортировкой вставками (`insertion_sort`).
- Слияние соседних серий (`merge`).
- Поддержание баланса длин серий с помощью стека (`balance_stack`).
- Галопирующий поиск (`gallop_left`, `gallop_right`) для ускорения слияния длинных последовательностей.
- Генерация тестового массива целых чисел (`random_array<T>`).

В `main.cpp` создаётся массив из 20 000 случайных целых чисел, выполняется сортировка и проверяется, что элементы расположены по неубыванию. При обнаружении нарушения выводится `NOT SORTED`.

### 5. Калькулятор арифметических выражений

В `SortStation.cpp` реализован калькулятор, который преобразует введённое выражение в обратную польскую запись (RPN), а затем вычисляет результат.

Поддерживаются операторы и функции:

- Арифметические операции: `+`, `-`, `*`, `/`, `^`.
- Тригонометрические функции: `sin`, `cos`.
- Круглые скобки.
- Приоритеты операторов при преобразовании выражения.
- Вычисление выражения с помощью стека чисел.

Токены выражения разделяются пробелами. Функции `sin` и `cos` вызываются из стандартной математической библиотеки; аргументы передаются в радианах, если используются стандартные реализации C++.

### 6. Вспомогательные функции

В `features.cpp` и `features.h` реализованы:

- Настройка кодировки консоли Windows для вывода русских сообщений (`SetRus`, `UnsetRus`).
- Проверка, является ли строка целым числом (`is_num`).
- Преобразование символа-цифры в число (`char_to_int`).
- Преобразование строки в целое число (`str_to_int`).

## Сборка и запуск

Проект настроен для Visual Studio и использует Windows API (`windows.h`) для управления кодировкой консоли. Для сборки откройте файл `Studing.vcxproj` в Visual Studio и соберите проект.

Текущая точка входа `main.cpp` запускает тест сортировки Timsort. Функция `calculator()` реализована отдельно и не вызывается из `main()`.

## Ограничения текущей реализации

- Ввод выражения для калькулятора разбивается по пробелам: используйте пробелы между числами, операторами и функциями, например `3 4 +`.
- Обработка некорректных выражений и деления на ноль ограничена; калькулятор предполагает корректную структуру RPN.
- В `calculate_RPN` числа преобразуются в `int`, поэтому дробная часть входных чисел не поддерживается, хотя результат вычислений хранится как `double`.
- Перед использованием стека в `top()` нужно убедиться, что он не пуст.
- В реализации контейнеров есть граничные случаи, которые стоит дополнительно проверить, например вставку в пустой двусвязный список и удаление его единственного элемента.
